# TAI Switch UI 与动效设计说明

日期：2026-10-14。依据当前工作区实现整理；这是设计与实现说明，不是测试、原生体验或验收记录。逐页覆盖范围另见 `UI_REBUILD_COVERAGE.md`，不能把共享组件覆盖等同于所有页面均已重新设计。

## 结构与视觉

界面采用温暖宣纸内容区、墨色导航和有限朱砂强调。明暗主题使用同一层级与语义色；状态、数值和操作优先于装饰。取消原外壳的大面积装饰圆弧与侧栏盖板动画。

| 区域           | 当前结构与约束                                                                                                                                             |
| -------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 外壳           | 客户端独立下拉选择；工作台、用量、会话与配置资源形成稳定任务导航；应用、设置固定在底部。模式提醒、授权异常、今日用量与更新标记仍来自原查询。               |
| 客户端专属功能 | OpenClaw 工作区/配置、Hermes 记忆等保留既有页内入口；切换客户端后按原导航规则进入工作台，不伪造能力。                                                      |
| 页头           | 显式 `variant="client"` 才把客户端放在眉题、任务放在主标题。编辑器和会话页仍以原 `title` 为主标题；长标题与眉题可截断，操作与窗口控件保留独立区域。        |
| 供应商         | 概览交代当前使用和已保存渠道；卡片区分身份、真实状态、原地详情和主要动作。管理动作仍可从菜单到达；无健康数据时显示未检测。                                 |
| 用量           | 筛选带 → 成本主指标及请求/Token/缓存指标 → 趋势 → 明细。更多指标置于指标标题栏。初次读取失败显示 `--`，不会把未知解释成零。原聚合算法与查询语义保留。      |
| 设置           | 保留六分组；正文加入分组说明。宽屏分节标题和设置内容分列，窄屏顺序排列。同一个设置页实例内按分组保存、恢复滚动位置；原保存与危险操作机制继续负责业务状态。 |

侧栏展开宽度为 216px；未有手动偏好时，窗口小于 960px 自动收成 Windows 72px 图标轨（macOS 为 84px）。手动选择优先并持久保存。目录可以滚动；图标轨保留可访问名称与提示，不依赖触屏手势。

## 共享运动规则

统一入口为 `src/lib/motion.ts`、`src/styles/motion.css` 和 `MotionSurface.tsx`。数字是实现参数，不代表实测帧率。

| 场景                | 当前实现                                                                                                                                                                  |
| ------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 同层页面            | 持久 `MotionSurface` 只在 `motionKey` 改变时启动；240ms，8px 小位移与 0.82 → 1 透明度。快速改变目标时读取正在呈现的位置、取消旧动画并接续。首次挂载与普通数据轮询不重播。 |
| 导航、分段选择      | 选中底板使用 Motion；弹簧 `stiffness=420`、`damping=38`、`mass=0.85`。首次定位直接到位，后续变化重定向到最新位置。                                                        |
| 侧栏收放            | 240ms 宽度过渡，可反向；移除额外盖板、DOM 插入和临时层级改写。快速连续切换使用函数式状态更新。                                                                            |
| 按钮与输入          | 按钮按下缩放到 0.98，按下反馈 70ms、释放 180ms；禁用按钮不缩放。边框、颜色等短反馈通常 140ms；开关位移 240ms。                                                            |
| 页式编辑面板        | 从内容区右侧偏移 28px 进入，320ms；关闭小幅右移并淡出。实体底色保持文字可读，不用整页缩小或大面积模糊。                                                                   |
| 对话框、Sheet、菜单 | 对话框位移约 12px、缩放 0.98，320ms 打开；Sheet 右移起点 24px、320ms；菜单 4px/0.98、180ms。退出通常 140–180ms，退出层禁用指针事件。                                      |
| 展开内容            | 供应商详情使用局部 `grid-template-rows: 0fr → 1fr` 与透明度过渡；通用折叠内容按 Radix 测得高度展开。变化限定在当前区块。                                                  |
| 主题                | 已初始化后，仅主要表面背景与边框约 200ms 过渡；不做全屏模糊、截图揭幕或图表从零重画。                                                                                     |

常用缓动为 `cubic-bezier(0.22, 1, 0.36, 1)`。CSS 时长令牌为 140/240/320ms；Motion 时长令牌另保留 press 120ms、feedback 180ms、page 240ms、panel 320ms，按具体交互选用。

## 模式、详情与编辑的连续性

**查看模式与启用模式分开。** 模式分段底板表示当前查看的直连/路由/聚合页；生效模式由原状态圆点与颜色表示。应用更改期间显示真实 pending 文案，成功状态由原业务结果驱动，不能用底板移动冒充配置已写入。

**供应商详情原地展开。** 点击名称旁的详情按钮展开请求地址、备注与连接状态，保留卡片身份、列表滚动及搜索上下文。首次访问详情后内容保留，收起时隐藏可访问内容；这里不是共享元素的跨页形变。拖拽包装层继续独占排序 `transform`，卡片不叠加竞争变换。

**新增与编辑保留原表单。** 新增沿用预设选择 → 表单步骤，表单位于持久 `MotionSurface` 内，不为过渡设置新业务 key。编辑等待初始配置投影就绪后再打开面板。关闭、返回和取消先经过既有 `requestLeave` 草稿保护；继续编辑时不因动画销毁输入状态，确认离开后才关闭。

**页面身份仍由业务决定。** `App.tsx` 的外层 `MotionSurface` 持久存在，内层 `Fragment` 保留原 key 规则：设置为 `settings`，应用页为 `app`，其它页面为 `currentView`，包括 Skills 发现页原有边界。这避免为动画额外重挂载，也不宣称跨所有页面自动缓存所有表单。设置按 section、用量明细按 tab 触发局部动画，轮询结果不作为 motion key。

## 焦点、浮层与减少动态效果

- Radix 继续管理通用对话框、菜单、选择器的焦点、Esc、关闭与滚动锁。具体组件原有关闭规则优先于动画。
- 页式 `FullScreenPanel` 覆盖主内容区，保留侧栏导航。底页和下层面板使用 `inert`；顶层接收 Esc，子菜单已消费的 Esc 不再触发父面板关闭。输入框内关闭只对具备草稿保护的调用显式启用。
- 退出面板立即进入 `inert`/`aria-hidden` 状态，并临时命名空间化内部 ID；退场画面不形成第二组可操作字段。关闭后在原元素仍存在、可交互的条件下恢复焦点。
- 客户端菜单支持键盘打开、选项导航及 Esc 回焦；侧栏提供 `Ctrl/Meta + \` 折叠快捷键、跳到正文入口及可见焦点。
- `prefers-reduced-motion` 下，页面与面板移除空间运动，滑块直接定位，侧栏/详情/搜索过渡关闭；全局 CSS 缩短其余动画并恢复原生自动滚动。功能、文字状态与焦点规则不依赖动画完成。

## 性能与业务边界

优先使用 transform/opacity，但侧栏宽度、详情网格高度、通用折叠高度和可变宽选中底板仍可能触发布局。这些是有界局部过渡，不应被描述成全部由合成器完成。浏览器不支持 WAAPI 时页面内容仍立即更新；原生滚轮、滚动条和系统手势不被替换为自制惯性。

用量趋势保留 `isAnimationActive={false}`。没有新增以轮询为触发条件的图表、页面或数字计数动画；请求加载与导航动画各自运行。尚需按目标 Windows WebView2、窗口尺寸、系统缩放与数据规模检查实际帧时、长任务和布局开销；**60fps 是目标，本文不作实测达标声明**。

本轮导航、选中底板、原地详情与视觉过渡不新增付费模型调用。连通性检测、同步、供应商切换、保存等仍是原有显式业务动作，不能为了演示自动触发真实付费请求。后端 API、数据库、计费算法、配置写入规则及凭据保护保持原契约；未知状态不得补成正常、余额或成功。

## 实现分工

本轮 Astra 负责外壳（侧栏、客户端切换器、页头、折叠行为）以及设置/用量布局的设计与实现。共享动效基础设施、供应商工作台、表单/模式/浮层及集成工作由主代理与其它协作代理完成。不能据此称全部界面均由 Astra 实现，也不能把这份说明当成全部页面重构或原生验收完成的证明。
