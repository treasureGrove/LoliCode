# 下一版：酒馆预设人物卡

实现日期：2026-10-19。本项为源码改动，未增加版本号、未打包或发布安装包。

## 使用方式

在应用中心添加「酒馆」后，打开酒馆的「预设人物」。新角色库也有「从预设人物开始」入口。可以按人物、作品、标签搜索，展开「看看开场」，点击「开始故事」后自动加入角色库并打开新故事。没有配置模型时也能选卡、查看开场，继续生成需要已有可用模型渠道。

首批包含 sillyLoli、初音未来、芙宁娜、胡桃、钟离、卡芙卡、流萤、芙莉莲。这是人工精选清单，不代表实时热度排名。每张卡有角色描述、性格、场景、开场白、示例对话、系统提示、后置提示、备用开场及两条世界书条目。当前内容以中文编写，提示中允许跟随用户指定的语言。

人物卡编译进 Rust 本体，不访问外部卡站或图床。sillyLoli 复用应用已有的本地看板娘 PNG，其余卡片使用文字徽记，不加载外部立绘。

## 数据行为

- 预设不是自动灌入用户库；只有点击「开始故事」才添加。
- 同一预设使用固定标识，多次添加只保留一张卡，每次可以创建独立故事。
- 已添加的卡片不会被目录中的新内容自动覆盖；导入卡、自定义字段、已有故事均保留。
- 添加成功但故事创建失败时保留卡片，展示错误并允许重试。
- 本地存储损坏或标识被其他卡片占用时拒绝覆盖原数据。
- 目录可浏览、搜索和滚动；正在准备故事时防止重复提交，当前故事生成中时不可从目录另起故事。
- 开场白直接写入故事，不发送模型请求；后续生成沿用原有酒馆模型服务、故事持久化和用量归属。

## 手动验收

- [ ] 新用户从应用中心添加酒馆，能直接打开预设目录，不需要先下载第三方人物卡。
- [ ] 搜索「原神」「犬娘」「芙莉莲」分别能筛出对应人物；无结果时有明确提示，清空后恢复。
- [ ] 展开开场预览，点击任一人物「开始故事」，角色入库并显示对应开场；不自动消耗模型额度。
- [ ] 配置可用模型后继续对话；打开「上下文」，可看到角色设定、示例与常驻世界书，命中关键词的世界书也会加入。
- [ ] 同一人物再次开始，角色库不重复，原故事保留，新故事单独保存。
- [ ] 退出后重开，已添加人物和故事仍在；升级目录不覆盖本地已有内容。
- [ ] 原有 PNG／JSON 导入、模型选择、上下文预览和故事删除仍可用。
- [ ] 断开外网仍能浏览目录、开始故事、看到 sillyLoli 头像；模型生成仍需要渠道网络。
- [ ] 缩小窗口，目录能滚动，搜索和关闭按钮仍可操作，浅色与深色主题可读。
