# v1.0.3 账户与仅直连：本地验收

日期：2026-10-26。产品版本 1.0.3，原生更新版本 4.1.3，Android alpha.4。
这是源码与本地测试记录，不是正式发布、真实账户闭环或公网 NAT 通过声明。

## 已验证

- 原有用量、图片、逐题提问、酒馆、Office、MCP、工具搜索等改动此前完成
  277 个前端文件 / 3254 项测试及相关实际界面检查；新增账户直连后增量
  前端 21 项、类型检查和生产 renderer 构建通过。
- 新生产依赖图的全量回归中，原生 Agent 154 项全部通过；桌面 Rust 库
  3975 通过、0 失败、15 忽略。随后旧配对封存的最终增量验证为 mobile
  18 通过、0 失败、1 手动项忽略，非 test 生产编译检查通过。
  忽略项包括依赖真实外部凭据、引擎、WSL、
  性能诊断和需要单独启动的手机互通测试，未当作通过。
- 账户共享固定向量由 Node crypto 独立生成，Rust 与 Android 验证 P-256
  SPKI / ECDH / HKDF / AES-GCM 的相同输出，以及跨账户、错角色与篡改拒绝。
- Windows 原生 WebRTC 两端完成 20 KiB 加密包传输，选中候选对不是 relay。
  满事件队列后的关闭使用独立原子状态阻断，未因丢失关闭事件继续消费；
  首包早于异步 Open 回调的顺序也已处理。
- 生产启动不再恢复旧配对的 WebSocket 或撤销重试任务；旧创建/批准 IPC
  明确停用。数据库历史与系统凭据库保留，旧房间在准入之前被拦截，
  不读取旧 vault 或启动网络任务，避免升级后的反复无效连接。
- 发布前复审修复了桌面切换账户复用设备身份的问题。UUID/P-256 密钥按
  规范账户 ID 独立保存，A→B→A 恢复各自身份；并发首次读取只生成一次，
  退出后的旧请求不能恢复内存身份。旧 installation 条目保留，只有历史
  房间唯一证明归属时才迁移。真实本地 Node 服务配合虚构论坛与 vault 的
  A/B/A 注册均成功，跨账户房间拒绝。最终 mobile 26 项通过、1 手动项
  忽略，论坛账户 13 项通过，非 test 生产编译检查通过。
- Android JVM 35 项、模拟器 12 项 instrumentation（含 10 项实际 Compose
  交互）、小米 8 Lite 的原生 SDK 与 AndroidKeyStore 2 项通过。
  模拟器使用既有 AVD 的只读模式，未改写原 userdata。
- 后续后台在线显示修复的最终 Android JVM 为 43 项通过，另有 11 项
  Compose 交互、debug 构建与 lint 通过。目录心跳与已验证直连分别展示；
  更新失败、缓存过期及回到前台待刷新时显示“状态待确认”，设备列表保留。
  在线显示本身不能解锁任务。首次刷新中途失败后，仍会在下一轮恢复已批准
  的授权申请；本地真实 HTTP 失败重试用例确认没有重放任何写操作。
- 原生后台隐藏窗口后仍发送心跳。只读本地生命周期验证确认 WS Pong 和
  无 WS 时的 HTTP presence 均能续报；停止续报满 120 秒后目录转离线，
  手机正常轮询另有最多约 30 秒延迟。该验证没有使用真实账户。
- Android 35 模拟器与 Windows webrtc-rs 原生互通，双向各传 20480 字节
  明文对应的认证加密包，最后确认包也经过 AES 验证。桌面发出 27530 字节、
  收到 27528 字节密文；辅助 HTTP 共 1861 字节，仅两个 SDP 请求。
  实际任务数据经过 SDK UDP / DTLS / SCTP，任务 WebSocket 字节为 0，
  TURN 未配置，选中的候选对不是 relay。ADB reverse 只承载 TCP 3127 信令。
- 独立设备服务 50 项、Linux 更新脚本故障注入 16 项通过。默认不接受匿名
  旧版建房，不转发任务包或推送；所有房间共享有限的信令与元数据预算。
  更新脚本覆盖 stop / rename 已生效但 CLI 报错、异常容器和 nginx 失败回滚。
  公网新服务已部署，Windows 外部探测确认 directOnly、账户目录未认证 401、
  匿名旧建房和未认证任务帧拒绝。更新过程保留了首次失败和回滚记录；
  第二次严格就绪检查实际观察到 nginx 重载后的 404→401 窗口再通过。
- Android alpha.4 使用原有发布证书完成 R8 构建、签名、16 KiB ZIP 与原生
  ELF 对齐检查。最终正式字节仍须与冻结源码重建产物及公开下载核对。

## 保留的待验收项

小米与 Windows 的首次 host-only 真实跨端测试没有建立连接；两端没有
共同的 IPv4 /24，该次测试未使用 STUN。此失败没有回退到任何任务中继。

自建 STUN-only 服务已在既有阿里云 ECS 单独启用，TURN 禁用，仅监听
UDP 3478，并有独占、持久化的入站/出站速率预算。主机内部 Binding 成功；
两个外部来源尚未到达该端口，公网入口需要继续核实云安全组。

真实账户登录、真实手机手动点按、手机所属 Agent 任务/单次审批/停止完整
闭环、电脑焦点与 Win+L 仍未完成。本机 MIUI 拒绝 ADB 注入，既有选择是
保留用户手动输入，不修改手机安全设置；不能把模拟器交互当作真机通过。

旧配对候选包与 a3f25faf 账户候选包仅保留本地，不用于本轮交付；后者
未包含最终的账户身份隔离和手机在线显示修复。正式包须来自新冻结源码，完成
实际 NSIS、便携包与 APK 校验，并在公开下载后核对相同字节。
