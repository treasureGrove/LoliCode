## sillyDog 角色记忆（补充）

- [ ] 打开记忆面板，可以看到 sillyDog（小笨狗）的角色说明，以及标为「内置预设」的称呼、犬耳角色与「汪呜~」三条记忆。
- [ ] 改为其他称呼、修改角色或删除叫声后，刷新、重启均保持修改；清空所有记忆后不补回。
- [ ] 用户已有的称呼与语气偏好优先，预设仅作为默认角色风格传入模型，不写入不可编辑的系统人设。
- [ ] 用户已关闭记忆时保持关闭；容量已满时保留已有记忆，不挤出内容以添加预设。
- [ ] 实际渠道模型 ID 保持原值，sillyDog 用于内置角色与未来轻量模型的暂定命名。

一次初始化标记与记忆写入同一份本地文件；用户修改后不会因再次启动或未来提高预设版本而补回。记忆开关与权限确认逻辑继续生效。已用本地 HTTP 模型替身验证了实际请求上下文和重启后修改的持久化，没有使用真实模型额度。

## 独立任务与侧栏位置

- [ ] 未打开项目时，直接点击「新建任务」或「新建独立任务」，不弹出文件夹选择。
- [ ] 已打开项目时，「新建任务」仍在当前项目创建；点击右侧下拉箭头，可以选择「新建独立任务」。
- [ ] 独立任务集中显示在侧栏「独立任务」分组，支持恢复历史、重命名、归档等现有会话操作。
- [ ] 独立任务自动保存到应用管理的本地任务目录，文件目录与引擎配置、数据库分开。可通过右上角「独立任务」打开任务文件目录。
- [ ] 从项目任务切到独立任务，再回到原项目，未发送的草稿仍保留。
- [ ] 没有配置模型时，进入模型配置引导，不发送请求、不创建无效会话。
- [ ] 左侧底部固定顺序为「应用 → 更新 → 账户头像」，设置页也可以打开应用中心。

本次补充已通过 87 项相关界面测试、类型检查及 Rust 全量回归（3,909 项通过、14 项忽略）。本地浏览器使用真实组件与独立模拟数据验证了菜单、创建入口和导航顺序，没有向真实模型发送验收请求。

- [ ] 在应用中心添加「模型榜单」，侧栏出现入口；移除后入口消失，重新添加仍保留收藏。

- [ ] 点击图片打开应用内大图，支持 75%–200% 缩放、滚动查看、关闭按钮和 Esc。
- [ ] 每张图显示来源、截取日期；当前是 2026-10-19 的榜单局部快照，不是实时完整榜单。
- [ ] 输入关键词、切换综合／编程等分类、仅查看收藏，都能正常筛选。
- [ ] 首批三张图片随应用内置，约 170 KB，打开时无需 HTTP 下载；断网仍可查看。
- [ ] Arena 和 SWE-bench 当前未取得稳定可用的截图，明确显示暂无快照，并保留原站入口。
- [ ] 查看完整原榜／官方说明时才打开浏览器，不调用模型、不传模型凭据。

图片来源记录：`src/assets/discovery/SOURCES.json`。保留原图，没有重新绘制成绩、修改名次或将截取日期当作评分更新日期。
