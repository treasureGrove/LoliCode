# LoliCode v1.0.6

Windows 原生更新版本：4.1.6。

- 新增 Loli 秘书：在项目内协调工作对话、查看任务进度和结果，并处理需要授权或回答的待办。工作任务使用同一项目目录与既有模型、权限和用量系统。
- 通过对话创建和修改自动化：先澄清任务与时间，再生成配置卡，点击保存后生效。修复自动化页面长时间等待，保存重试不会重复创建任务。
- 新增持久消息队列：执行中可继续补充要求，按顺序发送；支持立即发送、删除和撤回编辑。队列以输入框上沿的紧凑窄条展示。
- 临时上游错误在尚未产生可见输出时自动重试，保留已经完成的工具结果；完善思考及工具过程中的图片预览。
- 增加模型供应商品牌图标，调整侧栏展开按钮与文件修改汇总条的间距。
- 提供正式版与开发版之间的手动普通会话同步；秘书及关联工作会话暂不单独同步，以保留任务关系。
- 更新桌宠视频动画、停靠与休息状态，并展示真实秘书任务动态。
- 修复社区个人空间链接，增加社区入口及打开失败提示。

自动化和后台工作需要保持桌面应用运行。关闭应用后保留记录，未完成任务需要明确继续，不自动重放已执行的工具。

本版提供 Windows x64 安装版、Tauri 更新签名和便携 ZIP。既有用户数据沿用原目录，更新前可自行备份。
