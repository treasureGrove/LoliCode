# LoliCode 4.0.21-rc.1 测试候选

本版用于收集安装、升级与交互反馈。稳定下载和自动更新清单暂时保留 4.0.20；候选包的构建、上传与链接以实际交付记录为准。

- 按需添加酒馆与虚幻应用，和工作台并列。移除应用入口保留角色、故事与工程记录。主 Agent 新增权限控制下的酒馆管理工具，UE 完整功能仍在接入中。
- 工作流可以编辑完整原文，保留注释与扩展字段，检测过期保存冲突。切换项目时不会打开旧项目的编辑器。
- 修复酒馆完成后仍显示生成中的问题，限制上游响应大小，并避免展示原始服务端错误体。
- 路径配置损坏或原数据目录不可用时进入恢复页，避免项目、渠道和 Key 因误开空库而看似丢失。修复路径配置前保留原文件备份；更新前继续创建数据库快照。
- 图片装饰资源支持独立签名更新和回退，默认看板娘与背景保留本地离线资源。前端脚本与原生功能仍随应用安装包更新。

补充调试通过 GLM 实际检查了自然称呼偏好跨会话和引擎重启召回、自动标题、图片与文件工具、工作流和酒馆生成。这些记录不代替指定 testkey、真实桌面操作、第二台电脑覆盖安装或 Unreal Editor 联调。SSH/WSL、完整 UE、前端行为热更新及腾讯保护下载线路仍未验收。
