# LoliCode v1.0.3

原生更新版本：4.1.3。支持 Windows x64 安装版与便携版，沿用现有更新签名和旧版升级通道。

## 用量与对话

- 重新整理用量面板的来源、渠道和费用展示，移除个人 GitHub Copilot 官方账单卡片；历史账单和配置保留。
- AI 对话支持显示渠道实际返回的图片，并保留混合文字、图片与历史记录。需要渠道和所选模型支持图片输出；软件本身不提供额外的图片生成服务。
- 提问交互参考 DeepSeek Harness，一次显示一道题，支持返回修改，全部答完后统一提交。
- 原生 Agent 增加 Glob、正则 Grep 与工具搜索。按需加载工具定义，继续遵守当前项目、后台任务和审批范围。

## 酒馆

- 调整内置角色的对话说明与示例，鼓励依据当前话题、角色偏好和已经发生的事件自然回应，允许短句与不同对话节奏。
- 开场情景和世界书作为背景，后续事件更新当前场景；示例在成功交流后淡出，失败发送不进入实际对话历史，截断上下文时保留完整问答。
- 内置旧卡只更新仍与已发布默认值一致的字段，保留用户修改、导入角色及已有故事内容。回复质量仍取决于模型，角色事实和偏好可能出现误判。

## Office 与 MCP

- 工作区新增 DOCX、XLSX、PPTX、PDF 只读预览，以及打开、读取、搜索和定位工具。表格可查看已有单元格值与公式，演示文稿支持页面和备注。当前版本提供内容查看与引用，不提供 Office 编辑或扫描件 OCR。
- 原生 MCP 使用 LoliCode 中显式启用的配置，在发送任务或主动连接时发现服务器工具；查看扩展列表不会启动服务器。
- 支持本地 stdio 与 Streamable HTTP 的 JSON/SSE 响应。工具按项目隔离，执行须遵守审批；Plan 模式可发现工具并拒绝执行。OAuth 和旧版独立 SSE 传输会明确报告暂不支持。
- 配置撤销、停止准备和取消请求会关闭相应连接并回收本地自有子进程；远端请求发生取消时，其已产生的副作用可能需要用户核对。

## 手机连接、发现与界面

- 手机登录同一 LoliCode 账户即可发现电脑，首次连接在电脑上确认，无需复制配对码。设备持有独立密钥，建立端到端加密的原生直连，可创建和查看手机所属任务、发送消息、停止任务并回复审批与提问。
- 仅直连：服务器只负责账号验证、设备发现和有限的加密连接协商，不转发任务内容、回复、图片或文件。无法打通时提示切换网络重试，不回退到中继；未配置 TURN。
- 手机任务使用独立后台范围，写入按次审批，桌面交互、Shell 和应用控制不在该范围内。电脑需要开机联网并运行 LoliCode；手机连接不等同于桌面屏幕远控。系统锁屏推送暂未启用。
- 完善发现页面、应用中心入口与 LoliCode 品牌界面，整理相关说明和多语言文字。

酒馆本地模型与运行时继续首次按需下载，安装包和便携包不附带模型权重。升级前请关闭应用并备份重要数据；便携版需完整解压并保留原有便携数据。
