状态含义：

- `inherited-sdk`：执行由官方包提供；宿主入口仍需单独确认。
- `equivalent-verified`：列明范围内已有等效实现与验收证据。
- `partial`：部分入口已有实现，备注中的差异仍未通过。
- `needs-host-ui`：公开能力需要宿主或前端接线。
- `blocked-platform-service`：所需目标平台或外部服务尚不可用。
- `intentional-adapter`：产品采用明确的宿主替换，不能冒称原版功能完全相同。
- `pending-audit`：尚不足以判断覆盖，不计为同步完成。
