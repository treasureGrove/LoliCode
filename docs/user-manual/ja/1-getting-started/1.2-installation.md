# LoliCode のインストールと更新

## パッケージの取得

[LoliCode ダウンロードページ](https://tools.treasuregrove.art/lolicode/)または [LoliCode Releases](https://github.com/treasureGrove/LoliCode/releases)から公開済みパッケージを取得してください。コミュニティアカウントは [lolicode.com](https://lolicode.com)を利用し、モデル提供元のアカウントとは別です。

Windows、macOS、Linux を対象としていますが、公開プラットフォーム、CPU、動作条件、署名状況はリリースごとに異なります。各版のダウンロードページと説明を確認してください。CC Switch の Homebrew、AUR、インストーラーは LoliCode の配布物ではありません。

## インストール

- **Windows インストール版**：CPU に合う公開済みインストーラーを取得し、案内に従います。
- **Windows ポータブル版**：ZIP を書き込み可能なフォルダーへ完全に展開してから起動します。
- **macOS / Linux**：そのプラットフォーム向けに公開されたパッケージだけを使用し、同梱の手順に従います。未提供の環境でのソースビルドは[貢献ガイド](../../../../CONTRIBUTING.md)を参照してください。

内蔵 Agent はアプリに含まれ、Node.js、OpenCode、ZCode の別途インストールは不要です。外部ツールを設定する場合は、そのツール自体の動作条件を満たす必要があります。

## 最初のタスク

1. 接続先・モデル管理で API 接続先または対応するモデルアカウントを追加します。
2. モデル一覧を取得して使用するモデルを選びます。利用可能な設定は接続先に依存します。
3. ワークベンチでプロジェクトフォルダーを開き、依頼を入力します。
4. コミュニティアカウントには左下のアバターメニューからログインできます。モデル提供元の認証とは別です。

## 更新

アバターメニューまたは更新ボタンからソフトウェア更新を確認できます。インストール版は [LoliCode 専用の署名付き更新マニフェスト](https://tools.treasuregrove.art/lolicode/updates/latest.json)を使用します。

ポータブル版は新しい ZIP 全体を取得し、旧プロセスを終了してから、データを残してプログラムファイルを置き換えます。事前に設定をバックアップし、異なる版のプログラム資源を混在させないでください。版ごとの移行説明がある場合はそちらに従います。

## データと互換性

LoliCode は互換性のため、歴史的なデータフォルダー `~/.tai-switch` を引き続き使用します。設定やデータベース内の旧名称は互換性のためであり、元の製品をインストールする必要はありません。ポータブル版の保存先は同梱の説明に従ってください。複数プロセスで同じ本番データを同時使用せず、更新のためにデータを削除しないでください。

問題は [LoliCode Issues](https://github.com/treasureGrove/LoliCode/issues)へ、タイトルと具体的な現象だけで報告できます。アプリの版、OS、パッケージ形式、スクリーンショット、秘密情報を除いたログは任意です。
