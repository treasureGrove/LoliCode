# LoliCode 安装与更新

## 获取安装包

只从 [LoliCode 下载官网](https://tools.treasuregrove.art/lolicode/)或 [LoliCode Releases](https://github.com/treasureGrove/LoliCode/releases)获取本项目公开发布的包。社区账户使用 [lolicode.com](https://lolicode.com)，与模型渠道账户分开。

Windows、macOS、Linux 都是产品目标，但每个版本实际提供的平台、架构、系统要求和签名状态，以该版下载页与发布说明为准。不要使用 CC Switch 的 Homebrew、AUR 或安装包作为 LoliCode 安装方式。

## 安装

- **Windows 安装版**：下载当前版本提供的对应架构安装器，按向导安装。
- **Windows 便携版**：下载便携 ZIP，完整解压到可写目录后运行主程序；不要直接在压缩包中运行。
- **macOS / Linux**：仅使用当前发布明确提供的对应平台包，按该包附带说明安装。没有发布包的平台可参考[贡献指南](../../../../CONTRIBUTING.md)从源码构建。

内置 Agent 随桌面程序提供，不要求用户另装 Node.js、OpenCode 或 ZCode。外部工具的配置功能仍需对应工具自行满足其运行条件。

## 第一次使用

1. 打开「渠道与模型」，添加 API 渠道或支持的模型账户授权。
2. 获取模型目录，选择要使用的模型；可用参数以实际渠道能力为准。
3. 回到「工作台」，打开项目文件夹并开始任务。
4. 社区账户可通过左下角头像菜单登录；它不会代替模型渠道的授权。

## 更新

左下角头像菜单中的「软件更新」或更新入口可检查新版。安装版使用 [LoliCode 独立签名更新源](https://tools.treasuregrove.art/lolicode/updates/latest.json)，请按界面提示下载和安装。

便携版按下载页获取完整新版 ZIP。退出旧进程后替换程序文件，保留原有数据；先备份自己的配置，不要把新版程序与旧版资源混装。发布记录对特殊迁移另有说明时，以该版说明为准。

## 数据与兼容性

LoliCode 为兼容已有数据，继续使用历史数据目录 `~/.tai-switch`；历史数据库和配置中的旧名称属于兼容性标识，不代表需要安装上游产品。便携包的数据布局以包内说明为准。不要让多个进程同时使用同一份正式数据，也不要在更新前手动删除数据目录。

问题反馈请使用 [LoliCode Issues](https://github.com/treasureGrove/LoliCode/issues)，并附系统、应用版本、包类型及脱敏复现信息。
