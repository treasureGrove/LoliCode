# LoliCode installation and updates

## Get the application

Use the [LoliCode download page](https://tools.treasuregrove.art/lolicode/) or [LoliCode Releases](https://github.com/treasureGrove/LoliCode/releases) for published packages. Community accounts use [lolicode.com](https://lolicode.com) and are separate from model-provider accounts.

Windows, macOS, and Linux are product targets. Available platforms, architectures, system requirements, and signing status depend on each release. Check its download page and notes. CC Switch Homebrew packages, AUR entries, and installers install the upstream product, not LoliCode.

## Install

- **Windows installer:** choose a published installer for your architecture and follow its setup wizard.
- **Windows portable:** fully extract the portable ZIP into a writable directory before launching the application.
- **macOS / Linux:** use only packages explicitly published for that platform and follow their included instructions. For platforms without a published build, see [Contributing](../../../../CONTRIBUTING.md) for source development.

The built-in Agent ships with the application and does not require a separate Node.js, OpenCode, or ZCode installation. Configuring an external tool does not remove that tool's own runtime requirements.

## First task

1. Add an API channel or a supported model-provider authorization in **Channels and models**.
2. Fetch the model catalog and choose a model. Available options depend on that channel.
3. Open a project folder in **Workbench** and describe your task.
4. Optionally sign in to the community account through the lower-left avatar menu. This does not authorize a model provider.

## Update

Use **Software updates** in the avatar menu or the update entry. The installer edition uses the [independent signed LoliCode update manifest](https://tools.treasuregrove.art/lolicode/updates/latest.json).

For a portable edition, obtain the complete new ZIP, close the old process, and replace the application files while retaining your data. Back up your configuration first and avoid mixing program resources from different versions. Follow any version-specific migration notes.

## Data and compatibility

LoliCode retains the historical data directory `~/.tai-switch` for compatibility. Compatibility names in configuration or database files do not require an upstream application installation. Follow the included instructions for portable data layout. Do not run multiple application processes against the same production data or delete that data as part of an update.

Report problems in [LoliCode Issues](https://github.com/treasureGrove/LoliCode/issues), including the application version, OS, package type, and redacted reproduction details.
