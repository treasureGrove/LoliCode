# 缎带星图 UI 接入

2026-10-16。已将用户认可的服饰装饰方向接入真实 React 应用。风格来自本项目角色服装的酒红缎带、蓝绿胸针、奶油褶边与细金线；不把人物、耳朵、头发或尾巴做成界面形体。

## 视觉层级

- 主 Agent 是阅读和操作中心。工坊背景限制在边缘，中央为连续的纸面阅读栏，不再用一张大圆角卡片包住全部会话。工具记录继续默认折叠。
- 精修 PNG 边框用于项目侧栏，采用九宫格切片以适应拖动宽度。全局导航轨道用小型宝石标记，避免重复堆叠蝴蝶结。
- 输入区保持紧凑高度，使用单层细边和顶部小型 PNG 胸针，工具栏不再为大配饰预留空白。焦点由整个输入容器显示，textarea 不额外绘制矩形框。模型按钮优先显示模型名，完整渠道信息保留在标题提示与选单中。
- 设置、渠道和其他管理页降低背景强度。设置正文有独立阅读底板；表格、代码与弹层使用实色表面。
- 深色使用低饱和莓黑与酒红；浅色使用干净奶油纸色，消除低透明暗图造成的灰雾。现有主题选择继续生效，不覆盖用户的明暗偏好。
- 页眉统一标题、模型摘要与状态的层级。预览改为作品检视器：文件名、路径输入、操作与画布分层，隔离说明默认折叠，源码和图片分别使用合适表面。

## Q 版看板娘

用户选定的 Q 版形象作为独立看板娘放在项目侧栏底部，不把角色形体混入装饰边框或操作控件。图片常规高度为 144 px，矮窗口缩为 92 px；采用正常布局占位，项目与会话列表独立滚动，不遮挡对话、输入框或文件预览。

看板娘可直接收起，或在设置 → 通用 → 外观的「显示看板娘」中重新开启。显隐选择即时保存，与华丽／柔和／简洁装饰模式独立。项目侧栏折叠，或因窄窗口与文件预览而暂时隐藏时，看板娘随之暂隐，不改变用户的显示偏好。

产品素材 `src/assets/atelier/companion.png` 原样复制自 `design/ip/D-pinkdog-q-v1/standing.png`；保留已选角色和服装，未重新生成或修改形象。生成来源记录位于该设计目录的 `generation.json`。

## 设置与菜单

设置 → 通用 → 外观新增「界面装饰」：

- 华丽：工坊背景、侧栏饰边与胸针。
- 柔和：关闭场景背景和侧栏大边框，保留低调配饰。
- 简洁：移除图片装饰，保留统一配色。

「背景氛围」控制华丽模式的背景强度。设置即时保存于当前设备的 `lolicode.interface-appearance.v1`，支持跨窗口同步，不写入模型渠道配置。损坏的本地设置会回退到默认值，存储不可用时仍能在当前窗口使用。

模型、思考档位、会话、项目、Select、Popover、Dropdown 和子菜单共用表面、选中态、焦点环与边线。项目管理菜单改为 Radix 浮层，支持键盘关闭与焦点返回，避免被滚动侧栏裁切。原有项目置顶、移出列表和会话数据契约保留。
