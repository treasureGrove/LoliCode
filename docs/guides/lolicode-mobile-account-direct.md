# LoliCode 手机账户与直连

Android alpha.4 / Windows 产品 v1.0.3（原生 4.1.3），2026-10-26。
本文描述本轮源码；正式下载地址与完整交付结果以相应发布验收记录为准。

## 连接步骤

1. 在电脑头像菜单登录 LoliCode 账户，打开“连接手机”。
2. 点击“允许我的手机发现此电脑”。名称用于在手机上区分多台电脑。
3. 在 Android 客户端登录同一账户，选择电脑并请求连接。
4. 在电脑首次确认这是自己的手机。确认绑定具体设备密钥，不复制配对码。
5. 手机显示实际直连成功后，选择电脑已打开的项目与模型，创建任务。

电脑须保持开机、用户已登录、联网并运行 LoliCode。通信由原生后台模块
持有，打开聊天页面不是连接或执行的前提。未实现注销后运行或远程开机。

## 数据从哪里走

服务器只负责验证账户、保存同账户设备目录和有限的加密连接协商。
STUN 辅助发现公网地址；服务器不转发任务、回复、图片和文件，没有 TURN。
任务数据使用原生 WebRTC DataChannel 在手机与电脑之间传输，两端承担
主要流量；服务器仍有少量身份验证、设备发现、保活和打洞流量。

“支持直连”表示客户端具备能力。“已直连”仅在真实原生数据通道建立后
显示。部分公司网络、运营商 NAT 或禁用 UDP 的环境无法打通，客户端明确
提示切换网络重试；不会偷偷改用中继。可尝试同一可达局域网、允许 UDP
的网络或具有可用 IPv6 的两端；这些条件不保证所有网络均可连接。

## 账户、加密与撤销

账户密码只用于论坛 HTTPS 登录，不保存密码，不用密码或论坛令牌作为
通道密钥。服务器换发仅限手机连接服务的短期设备票据。每个安装持有独立
P-256 身份密钥，首次设备授权通过 ECDH/HKDF 加密传递新房间密钥。
后续任务还使用独立的 AES-GCM 认证加密、方向绑定、时间窗和重放检查。
电脑私钥进入系统凭据库；手机私钥和账户凭据由 AndroidKeyStore 密封保存。

设备目录按账户隔离。账户切换、退出、撤销、票据到期或控制连接断开会
关闭对应直连。重连重新认证并读取当前快照，不自动重发修改请求。
密钥固定后不能静默替换。首次身份目录仍依赖受信任的账户服务与电脑
本地确认；此实现不声称具有 Signal 双棘轮或绝对防劫持能力。

在电脑“撤销连接”可停止该设备访问。“关闭账户连接”移除这台电脑的
账户连接身份并关闭对应通道；离线时也先在本地阻断访问。不要把删除本地
手机列表误当作已经成功撤销远端身份。

## 任务与测试边界

手机任务仍使用独立会话所有权、明确项目绑定和后台安全策略。支持文件
读取、检索，以及逐次审批的写入/补丁、提问和停止任务。Shell、Git、构建
和桌面点击不在此范围；账户登录和 P2P 不扩大工具权限。
系统锁屏推送继续暂缓，手机回到前台读取状态。

验收分开记录：固定跨语言加密向量、原生两端数据通道、真实手机 SDK、
手机与 Windows 原生互通、账户完整闭环、跨网络 NAT、后台焦点和 Win+L。
一个层次通过不能代替其他层次。真实手机登录密码由用户自行输入，不从
设备或系统凭据库提取；MIUI 未允许自动点击时保留人工操作步骤。
