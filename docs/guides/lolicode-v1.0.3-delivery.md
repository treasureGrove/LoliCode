## 功能范围

1. 整理用量来源和汇总展示，移除用量页的 GitHub Copilot 官方账单卡片。
2. 补齐对话图片的接收、显示和恢复；提问界面按题逐步作答，可返回修改，答完统一提交。
3. 改善酒馆的角色上下文与回复节奏，更新内置角色默认对话，并保留既有故事和自定义角色。
4. 新增 DOCX、XLSX、PPTX、PDF 文档的预览、读取和搜索；MCP 工具支持按需发现并审批调用。
5. 手机通过同一 LoliCode 账号发现电脑，经电脑首次确认后建立独立加密通道；优先尝试原生直连，受限网络可使用有流量上限的加密文本通道。
6. 手机可选择、同步并继续电脑已注册项目中的既有会话，按需读取历史和完整长回复；完整同步模型目录，单次逻辑消息上限为 1 MiB。
7. 改善设备票据续期、临时连接冲突恢复与完成通知的发送顺序。重连后读取状态，不自动重发问题、创建任务或审批操作。

文档预览提供实际解析的段落、单元格、幻灯片和 PDF 内容，不承诺完整复现 Office 原始排版。酒馆改动改善默认上下文和节奏，不保证任意模型的每次回复都自然或不重复。

## 1 MiB、文本通道与重连语义

1 MiB 指完整逻辑 JSON 对象序列化后的 **1,048,576 个 UTF-8 字节**，包括 RPC 信封字段。小对象直接发送，较大对象经 zlib 压缩、分片、限速传输；接收方完成长度、顺序、解压、SHA-256 和 JSON 校验后，才向业务处理器或界面交付一次完整对象。目录不能因分片尚未收齐而只显示部分结果。具体契约见 [Companion logical JSON v1](../architecture/companion-logical-json-v1.md)。

本地边界与跨语言测试覆盖恰好 1 MiB、超出一字节、中文 UTF-8、损坏分片、拼接压缩流、超时与取消；完整 45 项模型目录已在真实手机上同步。**尚未进行生产链路 1 MiB 满负载实测**，逻辑上限不代表一次底层网络帧，也不是网络必达或不限时承诺。

文本服务的密文外层帧仍最多 8192 bytes，全局速率 8 KiB/s、账户速率 2 KiB/s、月度 2 GiB 硬额度保持不变。压缩不能替代加密，也不重置配额。图片、附件、工具原始输入输出、文件差异等不能借文本通道放行；文本模式审批仅可拒绝，批准仍需查看完整操作的通道或电脑端确认。

断线、账号变化、撤销或新连接 epoch 会丢弃旧的部分传输与未发送内容。重新连接会恢复目录、重新附加并读取所选会话；对未获确认的变更操作先核对状态，不自动重放 `message.send`、创建会话或审批。

## Windows 包与实际覆盖升级

Tauri 更新签名、trusted comment 校验及单字节篡改拒绝通过。实际 NSIS payload 的 **117 个文件**、默认扩展中的 **5 份许可证**及 **2 份官方 WebRTC 许可证**逐项哈希核对通过，提取后的真实程序通过离线运行检查。便携 ZIP 的 **122 个文件**解压后逐项匹配，并通过实际主程序离线检查。

本轮真实执行官方已发布 v1.0.2 安装器和新生产 v1.0.3 安装器，三步退出码均为 0：

1. 原生 **4.1.2** 安装到全新隔离目录，校验 **115 个文件**并运行实际离线检查。
2. 不传 `/D`，由 **4.1.3** 安装器识别原隔离目录并覆盖升级，校验 **117 个文件**及实际离线检查。
3. 不传 `/D`，通过 `/UPDATE` 重复覆盖 **4.1.3**，再次校验 **117 个文件**及实际离线检查。

三步均为 `/S /NS`，不传 `/R`。有效合成 SQLite 数据库和虚构设置的哈希在两次新包覆盖后保持不变。安装后 EXE 的完整 SHA 只允许已知的单处 `UNK → NSS` 安装类型标记变化；不忽略任意二进制差异。

测试后，HKCU 两个 RegistryView 的六组安装登记按存在性、值类型、值和 ACL 精确恢复，已知快捷方式字节恢复并复核。恢复以完整预期状态作 CAS，处理两个视图可能指向同一键的情况，不覆盖未知并发变更。最终只读核验与初始基线一致，无验收安装器或离线检查进程残留。

该安装验收使用隔离目录和虚构数据，没有运行正常 WebView、打开真实用户配置或替当前用户完成原安装的升级迁移。两次验收脚本自身的文件替换、Python 参数引号故障保留现场；修复后使用全新事务完成以上三步，没有将失败事务算作升级成功。
