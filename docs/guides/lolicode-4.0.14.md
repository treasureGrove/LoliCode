# LoliCode 4.0.14

- Agent 生成的项目内本地图片可在聊天中预览、放大和关闭。
- 保存渠道后自动同步编程模型目录，并保留手动刷新。任务执行时延迟同步，刷新后等待真实运行时应用目录。
- 模型状态改为可理解的说明；自动获取上游明确提供的上下文、输出上限和思考档位，缺失项不冒充已验证能力。
- 新会话使用固定源码的 ZCode 3.15.1 原生执行器，接入 Guarded / Plan / 完整访问、真实问答及单次授权。权限卡直接显示将执行的命令和涉及路径。
- 加入原生工作流、持久自动化及 SSH / WSL 远程项目入口，使用现有界面组件，整体视觉等待后续设计稿。
- 保留旧 OpenCode 会话与原始配置。修复迟到发送回执清除新草稿、请求不确定时重复提交及历史分页缺失提示。
- 应用内继续使用 LoliCode 自有更新地址和签名校验；更新前检查本地及远程任务状态。

Linux 远程资源目前准备为 x64 / glibc 2.34 及以上，连接在独立 LoliCode 目录部署。WSL 运行需本机实际安装兼容发行版。公开上游的 Computer Use 实现不可用，内嵌 MCP Apps 展示宿主尚未接入；普通 MCP 工具及原生本地技能、插件管理已接入。

安装版可以在“软件更新”检查新版本、下载并安装。便携版保留同级 `portable.ini`、`agent/` 和 `zcode-runtime/`，从下载页更新 ZIP。CLI / TUI 尚未作为 LoliCode 用户入口发布。
