## 生命周期与行为回归重点

1. **草稿与关闭**：返回、取消、Esc、切页、切客户端和托盘都要先完成保护，再结束编辑生命周期。“继续编辑”保留字段、选择与焦点；确认放弃才离开。保存失败保留草稿，保存中禁止重复提交。新增第二步返回预设页也要保护。
2. **面板存在期**：退场元素应立即不可访问、不可输入，并退出活动 ID 命名空间；背景锁与焦点恢复要覆盖真正退出的时间。嵌套面板关闭只影响最上层，同时首次挂载也不能把外层置顶。
3. **焦点**：内容区面板是可保留侧栏导航的区域，不应伪装为全窗模态。背景业务页不能被 Tab/点击操作。Radix 弹窗仍负责自己的焦点限制，消耗过的 Esc 不再触发父面板。关闭回到合理触发点，且不抢走用户主动移向侧栏的焦点。
4. **React 身份**：不要为进场动画改变业务页 key。`SwitchModePanel` 的客户端 key 与 `SessionManagerPage` 的共享来源 key 有业务含义。模式视图与真实生效模式分别管理，动画不驱动后端请求。
5. **异步表单**：Claude 新增读取配置底稿、编辑配置投影、Pi 就绪回调均已有过期结果保护，关闭再开或快速切换不能让旧请求覆盖新草稿。编辑不能因为 provider 对象刷新就重新初始化。
6. **列表**：详情/编辑进退保留当前列表、筛选与滚动。现有“切换客户端重置供应商滚动”是单独契约。布局动效不能覆盖 dnd-kit 的 transform；拖动结束不得误开详情。
7. **长标题和窗口控制**：供应商自定义长名称可能出现在主标题或上下文标题，两处都必须允许收缩；窗口拖动区域不能吞掉按钮点击。
8. **减少动态效果**：移除空间变化，保留真实状态和焦点行为。运行中切换系统偏好应停止当前动效；不能只在启动时读取一次。

优先行为测试：`tests/components/FullScreenPanel.test.tsx`、`AddProviderDialog.test.tsx`、`EditProviderDialog.test.tsx`、`SwitchModePanel.test.tsx`、`ProviderCardActions.test.tsx`、`ProviderCard.usageExpansion.test.tsx`、`tests/integration/App.test.tsx`、`tests/lib/unsavedChanges.test.tsx`。最终还需当前代码的全量前端回归、类型检查与生产构建；旧 2,612 项测试通过记录不代表本轮。
