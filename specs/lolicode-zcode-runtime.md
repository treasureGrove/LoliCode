# ZCode 3.15.1 行为接入

用户范围：现有编程功能及权限、项目会话、模型、技能插件，加上工作流、自动化、SSH/WSL 远程项目。现有界面样式和布局保持原样，后续按用户设计稿改版。

## 事实与所有者

- 基准为 `zai-org/ZCode` 的 `aac4755666d09fdcd70272fcf063c077a639015f`。复用其原生 CLI/runtime、V4 协议、Node services、工作流及远程连接；不把 OpenCode 的同名开关称作 ZCode 实现。
- Tauri 负责私有进程生命周期、已有渠道网关和 IPC。Node Host 负责原生服务与调度，CLI/runtime 负责会话、输入 admission、权限、事件日志与执行。Renderer 仅持未提交草稿和待对账请求。
- 新 ZCode 状态使用 LoliCode 独立目录。旧 OpenCode 引擎与数据库保留，按引擎标识路由旧会话，不覆盖或伪造历史迁移。
- `ask` 对应原生默认/build，`auto` 对应 `guarded`，`full_access` 对应 `yolo`；Plan 是独立状态。Guarded 的危险单次确认不得升级成项目永久授权。
- 自动化必须由真实持久服务及常驻调度 owner 执行，区分已接受、运行、终态和重启恢复。不能以 CRUD 或定时器触发本身冒充执行成功。
- 远程身份包含连接 ID 与工作目录；不按路径混用不同机器的会话。复用 SSH/WSL 的实际连接/部署流程，推理走受认证桥接，不向远端传上游 API Key 或 OAuth。

## 边界

私有 Host 仅绑定 loopback、使用随机 bearer 并限制消息大小；只有 Tauri 持有 Host 凭据。服务分派使用明确的公开 descriptor/method，不调用原型链和任意 JavaScript。跨进程事件保留真实顺序、请求身份和重连对账能力；EOF/退出时释放本轮子进程和租约。

默认不读取另一份 ZCode/OpenCode 安装的账号、配置或会话；不自动登录官方云服务，不新增付费推理。上游源码、Apache-2.0 许可及 NOTICE 与本项目 adapter 分开记录。

## 验收

真实原生运行时配合本机假模型验证创建/恢复、同 ID 幂等提交、排队、独立停止、模型与模式变更、Guarded 单次权限、Plan 拒写、默认技能/插件/MCP、工作流和持久自动化。远程连接用自有临时目录及测试连接，不操作生产项目；WSL 不可用时记录实际环境限制。前端回归不得改动样式/布局，并覆盖迟到 ACK 不清新草稿和不确定发送的对账/重试。

## 2026-10-25 原生工具补齐

官方源码已更新至 [3.16.2 / `3c5b227`](https://github.com/zai-org/ZCode/tree/3c5b227649371507ddc4eb46ac5133afe6db1cab)，相对固定快照新增了 [ToolSearch / DeferredToolCall](https://github.com/zai-org/ZCode/blob/3c5b227649371507ddc4eb46ac5133afe6db1cab/apps/zcode-cli/docs/design/v2/tool/19-tool-search.md) 与 Office 查看运行时。此处核对的是源码版本，GitHub 的 latest release 标签仍是 3.14.3。

当前默认执行链是 `lolicode-agent` Rust 本体。本轮为其新增 `tool_search`：从当前启用、当前项目及后台策略允许的工具目录中，按名称或说明查找工具并返回参数定义；执行时重新读取应用状态，停用后的工具不再出现在搜索结果中。搜索不授予权限。固定的 ZCode vendor 源码与清单未升级，以下能力由本体独立适配。

另外补齐本体此前缺少的两项只读文件工具，这两项是能力补齐，不是此次 ZCode 新增的工具：

- `glob`：按相对通配模式定位文件，支持 `**`，可缩小搜索目录。
- `grep`：按正则搜索内容，支持大小写开关、文件模式过滤和行号。原有 `search_files` 仍是字面量搜索。

两项文件工具复用项目路径检查及取消机制，限制遍历、文本扫描、结果数量与输出长度，跳过依赖和构建目录。Plan 可使用；当前远程执行器未实现这两项，因此远程目录不会广告或搜索到它们，不回退到本机占位目录。界面继续复用现有工具卡片，增加工具搜索标签和查询目标显示。

隔离的生产引擎测试覆盖搜索后真实执行 Glob/Grep、Plan 无写入、推理期间应用撤销、远程工具替换及手机后台目录过滤；不调用外部模型或读取用户项目。

### Office 文档与查看器

本地项目新增 `open_document`、`read_document`、`search_document`、`get_view`、`show_in_viewer`。DOCX 解析段落与表格，XLSX 展示工作表、单元格引用、公式与已有缓存值，PPTX 按幻灯片显示正文与备注；PDF 展示真实页面并提取文本供检索。界面复用工作台预览面板，支持定位、搜索和选区回报；文档版本使用 SHA256 校验，文件变化后旧选区及 PDF 字节请求会失效。

Office 面板是内容查看器，不提供 Office 原样排版或编辑，也不计算 Excel 公式。扫描 PDF 可以查看页面，不执行 OCR。PDF.js worker、字体、CMap 与解码资源随应用本地打包，不依赖远程 CDN。文档文本始终作为不可信材料，不执行宏、脚本、公式或外部关系。

解析与 IPC 沿用项目边界、实际文件句柄检查及大小限制；限制 ZIP 展开、PDF 流解压、对象数量、页数、正文和返回长度。远程项目不广告这些本地文档工具，也不会读取远程占位目录。

### MCP 与工具延迟加载

本体读取 LoliCode 自有扩展配置，支持 STDIO 与 Streamable HTTP MCP 服务。配置保存本身不启动进程；本地交互 turn 进入可取消的准备阶段后，连接启用的服务并获取工具目录。扩展面板也提供显式连接按钮，显示真实连接状态和错误。后台会话及远程项目跳过本机 MCP 连接。

MCP 工具默认不进入模型完整工具列表；`tool_search` 找到后，该会话才获得对应参数定义，并可直接调用或经 `deferred_tool_call` 分派。发现记录随会话持久化，但每次执行仍重新检查当前配置、项目、工具存在性及权限；停用、配置变化或撤销不会被旧发现记录绕过。这采用通用 JSON 工具协议，并未声称支持厂商专有的 deferred wire 格式。

MCP 调用一律需要现有审批，Plan 不可执行；服务自报只读不降低权限。STDIO 使用直接进程参数与受控生命周期；HTTP 不跟随重定向。取消与超时不自动重试；无法确认远程副作用已停止时进入现有不确定清理状态。服务 instructions 不注入模型上下文，图片回执经过格式与解码限制。OAuth 与旧式 SSE transport 尚未接入，配置时明确显示不支持。

验收包括真实本体引擎、loopback 模型与 MCP 服务之间的工具搜索、发现、审批和返回值链路，HTTP JSON/SSE 回执、STDIO 子进程清理，以及 DOCX/XLSX/PPTX/PDF 实际生成文件的解析与搜索。上游整包升级不在此次变更范围内。
