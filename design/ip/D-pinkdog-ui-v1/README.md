# D 樱桃舞台 UI 装饰稿

这轮交付聚焦于界面装饰本身：从已选定的 08 樱桃黑舞台服里提取酒红缎带、蓝绿宝石胸针、奶油白褶边、金线星纹和菱形挂链，构成一套克制、耐看的 UI 装饰。角色的身体、头发、兽耳、尾巴等形体不用于界面装饰。当前已接入真实产品，实施说明见 `docs/guides/cherry-atelier-ui.md`；此目录中的 HTML 继续作为独立设计稿保留。

## 预览

- 当前提案：打开 `costume-decorations.html`，查看「缎带星图」服饰装饰的 PNG 应用示例。侧栏使用 V3 精修图片；页面可调节背景遮暗程度、查看纯背景，并展开侧栏新旧对比。
- 打开 `raster-decorations.html` 查看新增 PNG 素材的完整应用示例，可调节背景遮暗程度，或切换到纯背景。月夜书房、透明蕾丝输入框和绒面侧栏均为独立图片，没有使用 SVG 代替。
- 打开 `decorations.html` 查看装饰在对话界面中的应用示例，包括窗口边角、标题装饰、细分隔线、徽章、消息气泡和输入框描边。
- 打开 `decoration-sheet.svg` 查看可复用装饰元素的矢量总览。
- `ornaments.svg` 是供 HTML 通过 SVG `<use>` 复用的隐藏图标 sprite；单独打开时为空白是预期行为。
- `index.html` 是此前制作的页面布局与交互研究稿，保留作参考，不代表本轮要实现的产品功能。

早期视觉稿的 Q 版角色图从 `../D-pinkdog-q-v1/standing.png` 引用。这里的 HTML 使用示例消息与静态状态，独立于真实产品。当前产品装饰使用服饰配件，不放置人物形体。
