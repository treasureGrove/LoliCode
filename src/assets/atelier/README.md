素材的绘制方式、完整提示词、来源设计路径和 SHA-256 保存在同目录 `provenance.json`；以上 `design/ip` 路径指本地设计过程。CSS 使用本地资源引用，Vite 会把使用中的图片与矢量框打包进应用。边框四角固定，只有无花纹的直边延伸；蝴蝶结与底部缎带分别定位并保持比例。柔和、简洁和高对比模式会隐藏相应装饰层，所有装饰层均不接收鼠标操作。

看板娘以应用窗口内的悬浮宠物呈现，角色绘制区域为 192 × 192 px，1:1 素材中角色约占九成高度，保留必要的透明边缘。拖动角色可调整位置，点击可摸头；脚边常驻圆形鱼干挂件，可点击或拖到角色身上投喂，冷却期间显示细进度环与秒数。靠近、键盘聚焦或触屏使用时显示两侧的休息／小窝入口。小窝面板用角色头像、当前状态、饱食与心情条和好感数值呈现养成状态，并依据实际面板尺寸选择上方或侧面位置，约束于窗口范围内。5 分钟无互动会自动休息。

`CompanionVideoActor` 的基础与互动使用五段本地透明视频：基础待机循环，首次展示和摸头播放互动回应，投喂播放进食；停靠时切换独立的 v5 坐靠或趴卧姿势。内置视频的父层反应时间为 5.2 秒，单次动作以视频 `ended` 为完成依据，父层提前恢复待机也不会截断尚未结束的回应或进食；重复摸头可以从头复播，好感仍遵守原有冷却，冷却期间再次点鱼干只提示等待。隐藏窗口时暂停视频和播放看门狗，恢复后继续。

每 35–60 秒检查一次待机小动作，仅在应用可见、角色清醒、没有拖拽或互动回应，且距上次交互至少 20 秒时触发；饼干与好奇动作交替，单次播放后回到基础待机。用户摸头、投喂、拖动和休息优先，待机小动作不会打断尚未完成的进食或互动回应；隐藏窗口和减少动态效果设置下不会启动新小动作。休息使用静态海报。

WebM 通过普通 Vite 资源引用打包为本地 `self` 媒体 URL，海报与原资源包识别图通过 `?inline` 嵌入渲染器。沿用现有 CSP，无需增加媒体或数据 URL 权限；运行时不依赖网络、外部账号或浏览器站点权限。解码前、视频失败及系统减少动态效果设置下显示同画布海报；待机小动作失败时可回到仍可播放的基础待机。资源包覆盖原角色时，直接显示资源包自己的图片，不加载内置视频，原有摸头 1.8 秒、进食 3.2 秒的反馈时间保持不变。

当前默认角色使用预生成视频，没有 Cubism / Live2D SDK、`.moc3` 或模型绑定文件。`CompanionRig`、`CompanionActor`、闭眼图与旧图集保留为历史代码和素材，不参与当前默认角色播放。`design/ip/D-pinkdog-rig-v1/turnaround.png` 是尾色统一后的正面、侧面与背面设计参考；不可见服饰细节为推导设计，不是运行时模型。旧网格素材的生成记录仍保存在同目录 `prompts.json`；v4 提示词与处理过程保存在 `design/ip/D-pinkdog-video-v4/`，v5 UI 坐卧见 `design/ip/D-pinkdog-ui-rest-v5/`。

v5 已接入真实工作台边缘停靠。拖动角色，使脚底靠近有效上沿 52 px 以内时显示轻提示，松手后在可见、足够宽且上方有空间的消息气泡和欢迎任务卡上坐下，在输入框外壳上沿趴下。停靠点按实际 DOM 几何对齐，并随滚动、窗口尺寸、侧栏与预览分栏布局变化跟随；目标移除、隐藏、被其他面板遮挡或切换会话后安全起身。系统消息、执行过程及包含代码的消息不作为停靠表面。

拖走、摸头、投喂或方向键移动会先离开停靠姿势，再恢复原有交互。停靠时只有接触线上方的身体保留拖动命中区域，垂在边缘下方的双腿、发梢和透明画布不挡输入、点击或选中文字。停靠不写入跨会话锚点，只保存安全的站姿位置。自定义资源包不启用内置角色的坐卧姿势；减少动态效果时仍保留对齐位置，显示该姿势的静态海报。

位置与养成状态保存于本机 `lolicode.companion.v1`，窗口变小时会约束回可见范围，面板可恢复初始位置；跨页面导航及项目侧栏折叠不会卸载宠物。收起后不显示悬浮召回按钮，可从外观设置恢复显示。显隐偏好仍与装饰模式独立。悬浮层仅角色、工具条和展开的面板接收鼠标操作，周围透明区域可直接操作工作台。
