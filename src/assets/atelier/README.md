# 缎带星图 · 应用素材

装饰图片由内置 image_gen 根据本项目已选角色稿生成，参考服装的缎带、蓝绿宝石、奶油褶边与金属挂链，不包含人物形体。独立看板娘使用用户选定的 Q 版形象，与界面装饰分开呈现。

- `ribbon-atelier.png`：背景，来自 `design/ip/D-pinkdog-ui-v1/costume-raster-v2/ribbon-atelier.png`。
- `sidebar-frame-light-9slice.svg`、`sidebar-frame-dark-9slice.svg`：当前深浅主题的矢量九宫格边框。源图为 128 × 128，四角切片与显示宽度均为 20 px，横纵比例一致；直边区只有可延伸的线条，中心不填充图片，由 CSS 绘制主题底色。
  亮色款沿用原有红缎带与香槟金边框的风格，将底色改为均匀的米白；按钮采用柔和酒红，选中态为浅暖灰红，文字使用暖棕与深酒红。顶部红色蝴蝶结放回左上角，深色款保持原有配色与装饰位置。
- `sidebar-ribbon.svg`：独立红色底部缎带，固定 140 px 宽并保持原始比例；顶部红色蝴蝶结复用 `brooch-accent.png`，固定 96 px 宽。两者不进入九宫格拉伸区域，面板宽度在 160–420 px 变化时保持原尺寸。
- `sidebar-frame.png`：旧版完整侧栏，来自 `design/ip/D-pinkdog-ui-v1/costume-raster-v3/ribbon-sidebar-refined.png`。保留原图和来源；已安装的深色资源包仍使用其原有整图及切片规则，通过临时 `data-resource-sidebar` 标记与新矢量框区分。
- `sidebar-frame-light.png`：2026-10-30 的首次亮色重绘稿，保留为设计历史；当前面板不再使用这张整图。
- `brooch-accent.png`：独立胸针，用于欢迎区与输入区，来自 `design/ip/D-pinkdog-ui-v1/costume-raster-v4/brooch-accent.png`。
- `companion.png`：用户已选的原始 Q 版看板娘，原样复制自 `design/ip/D-pinkdog-q-v1/standing.png`，SHA-256 未变；作为历史立绘及资源包 `companion` 默认识别键继续保留。当前默认动态角色与静态兜底使用下述尾色修正版，不覆盖这张原图。
- `companion-rig-v1.webp`：当前默认的完整透明立绘，1215 × 1295，无损 WebP。以已选粉发折耳角色为基础，按照用户纠正将尾巴主毛色改为可可棕、尾尖改为奶油白，与犬耳配色一致。来自 `design/ip/D-pinkdog-rig-v1/tail-matched-source.png`；同一张立绘用于连续形变、默认静态兜底与小窝头像。
- `companion-eyes-closed-v1.webp`：与默认立绘同尺寸、同坐标的透明闭眼覆盖层。由内置图像生成工具的闭眼稿中提取两处眼区，边缘以局部 alpha 遮罩羽化；眼区之外保持透明，不把闭眼稿的身体、尾巴或背景混入默认立绘。源稿、遮罩提取脚本、检查合成图与实际像素范围见 `design/ip/D-pinkdog-rig-v1/prepare-assets.mjs` 和 `asset-report.json`。
- `companion-motion-v2.webp`：已退役的 30 帧透明动作图集，6 列 × 5 行，每格 256 × 256。旧待机、进食、摸头、睡眠与悬空姿态，以及原始提示词、归一化和稳定性报告在 `design/ip/D-pinkdog-motion-v2/` 保留为设计历史；当前默认宠物不再加载或播放该图集。
- `companion-motion-v1.webp`：首版动作图集与 `design/ip/D-pinkdog-motion-v1/` 作为设计历史保留，当前默认宠物不再引用。

素材的绘制方式、完整提示词、来源设计路径和 SHA-256 保存在同目录 `provenance.json`；以上 `design/ip` 路径指本地设计过程。CSS 使用本地资源引用，Vite 会把使用中的图片与矢量框打包进应用。边框四角固定，只有无花纹的直边延伸；蝴蝶结与底部缎带分别定位并保持比例。柔和、简洁和高对比模式会隐藏相应装饰层，所有装饰层均不接收鼠标操作。

看板娘以应用窗口内的悬浮宠物呈现，角色绘制区域为 192 × 192 px，完整保留立绘四周的透明余量。拖动角色可调整位置，点击可摸头；脚边常驻圆形鱼干挂件，可点击或拖到角色身上投喂，冷却期间显示细进度环与秒数。靠近、键盘聚焦或触屏使用时显示两侧的休息／小窝入口。小窝面板用角色头像、当前状态、饱食与心情条和好感数值呈现养成状态，并依据实际面板尺寸选择上方或侧面位置，约束于窗口范围内。5 分钟无互动会自动休息。

`CompanionRig` 使用本地 WebGL 网格对同一张高分辨率立绘做连续二维形变：呼吸、轻微歪头、耳尖与发梢跟随、拖起时的悬空摆动及放下后的回弹；闭眼覆盖层跟随同一网格，在眨眼、摸头和休息时局部混合。动作姿态连续缓和切换，鱼干由组件内独立绘制的 SVG 沿路径送到嘴边，并随三次咬合逐渐减少，配以少量碎屑；没有借用第三方桌宠的图片或视频。进食为 3.2 秒、摸头为 1.8 秒，重复摸头可从头复播，好感仍遵守原有冷却；冷却期间再次点鱼干只提示等待，不中断当前进食。动画通过 `requestAnimationFrame` 更新网格和道具，不逐帧触发 React 状态更新；隐藏窗口时暂停，恢复时不累计隐藏时长。

两张默认素材均通过 Vite `?inline` 嵌入渲染器，现有 CSP 的 `img-src data:` 即可显示，播放不依赖网络、外部账号或浏览器权限。本轮素材由内置 `image_gen` 生成和本地处理，未通过豆包生成视频。解码、WebGL 初始化或绘制失败时，显示尾色修正后的完整静态立绘；系统减少动态效果设置下也显示该静态图。资源包覆盖原角色时，直接显示资源包自己的图片，不把内置角色的形变或眼区套到其他角色上。

这里使用的是轻量本地二维网格形变与表情覆盖，不是 Cubism / Live2D 模型，没有 Live2D SDK、`.moc3` 或模型绑定文件。`CompanionActor` 与旧图集仍留作历史代码和素材，不参与当前默认角色播放。`design/ip/D-pinkdog-rig-v1/turnaround.png` 是尾色统一后的正面、侧面与背面设计参考；不可见服饰细节为推导设计，不是运行时模型。四次生成的完整提示词、输入参考、工具原始输出路径及项目归档路径记录在同目录 `prompts.json`。

位置与养成状态保存于本机 `lolicode.companion.v1`，窗口变小时会约束回可见范围，面板可恢复初始位置；跨页面导航及项目侧栏折叠不会卸载宠物。收起后不显示悬浮召回按钮，可从外观设置恢复显示。显隐偏好仍与装饰模式独立。悬浮层仅角色、工具条和展开的面板接收鼠标操作，周围透明区域可直接操作工作台。
