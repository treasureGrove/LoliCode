# 业务界面

每个子目录集中一个业务的页面、专用组件、局部状态与样式。应用入口和跨页面导航在 `../app/`；基础控件和跨业务共享组件在 `../components/`。

- `agent/`：主 Agent 工作台、会话交互、工具与产物面板。
- `channels/`：统一渠道、模型列表与渠道预设。
- `apps/`：内置应用目录、外部 CLI 管理与配置入口。
- `settings/`：设置页面与账户设置。
- `discovery/`、`usage/`：发现与模型榜单、本机用量。
- `tavern/`、`unreal/`：酒馆和 UE 业务界面。
- 其余目录：供应商、会话、MCP、Skills、提示词、配置档、代理等对应业务的管理界面与配置组件。

数据调用经由 `@/lib/api/` 和 `@/lib/query/`。新增业务逻辑放入所属目录，文件过大时按状态、交互或独立面板拆分；不要仅为了缩短文件而创建无职责的分片。前端测试仍在根目录 `tests/`，维护时同步对应引用和 mock 路径。
