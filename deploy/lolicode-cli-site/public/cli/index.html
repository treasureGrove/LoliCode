开始使用

几行命令，见面。

先准备 Node.js 24 LTS ↗，再安装 CLI。

在 Windows CMD 或 PowerShell 中运行

npm.cmd install --global --ignore-scripts --prefer-online https://lolicode.com/cli/downloads/lolicode-cli-0.1.0-alpha.4.tgz
lolicode.cmd

如果终端提示找不到命令，重新打开终端后再试。

在 Bash / Zsh 中运行

npm install --global --prefix "$HOME/.local" --ignore-scripts --prefer-online https://lolicode.com/cli/downloads/lolicode-cli-0.1.0-alpha.4.tgz
export PATH="$HOME/.local/bin:$PATH"
lolicode

把 PATH 设置加入 shell 配置文件后，新终端也可以直接使用。

第一次见面

安装后，在项目目录打开 CMD 或 PowerShell，运行 lolicode.cmd。Linux 运行 lolicode。

lolicode › /connect

看到 lolicode › 后输入 /connect，按服务商提供的地址、模型名和协议配置渠道。CLI 的渠道独立于桌面版。

请等每条提示出现后再填写。缺少密钥环境变量时，在隐藏输入提示出现后粘贴 API Key。看到 you › 就可以输入任务。重开 CLI 后，若还缺密钥，再用 /connect 选用已保存的渠道。

常用命令

打开项目或执行任务

在项目里提需求，查看工具执行过程。默认在修改和运行命令前询问你。 

lolicode "./your-project"
lolicode run --dir "./your-project" "解释项目"

继续会话

对话和工具记录保存在本机，离开终端后可以恢复。

lolicode session list
lolicode -c
lolicode -s SESSION_ID

脚本输出

--format json 逐行输出 LoliCode 事件，--json 输出一个结果对象。 

lolicode run "检查项目" --format json
git diff | lolicode run "审阅改动" --stdin --json

配置与选择模型

在系统终端运行 auth login 配置渠道。缺少密钥时，粘贴临时 Key 会进入本次聊天，直接回车只保存渠道。已有密钥环境变量时，保存渠道后返回终端。

lolicode.cmd auth login
lolicode.cmd auth list
lolicode.cmd -m my-channel/MODEL

Linux 用 lolicode。对话中输入 / 查看命令，按 Tab 补全。

模型配置

你的模型，
也可以跟过来。

支持 OpenAI Completions、OpenAI Responses 和 Anthropic Messages 协议。用服务商提供的 API 基础地址和模型名，选择与之匹配的协议。

下面展示 Linux 环境变量配置。Windows PowerShell 使用 $env:变量名 = '值'。 

export LOLICODE_BASE_URL='https://api.deepseek.com/v1'
export LOLICODE_MODEL='deepseek-chat'
export LOLICODE_API_KEY='你的 API Key'

cd your-project
lolicode

还有这些小事

这一版支持哪些系统？

首版已验收 Windows x64 和 Linux x64。需要 Node.js 24.9 或更新版本。其他系统和架构会继续验证。

可以关闭颜色和动画吗？

可以。使用 --plain 或设置 NO_COLOR=1 关闭颜色，使用 --no-animation 关闭等待动效。

权限如何控制？

默认 review 模式逐次确认修改和命令。workspace 允许项目操作，plan 使用只读工具，full 显式开启无限制执行。脚本模式遇到确认请求时返回相应状态，方便你接手。

会话和配置保存在哪里？

默认位于 ~/.lolicode/cli。可以通过 LOLICODE_HOME 指定目录，使用 lolicode resume 恢复该项目的最近一次 CLI 会话。
