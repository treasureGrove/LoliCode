开始使用

几行命令，见面。

先准备 Node.js 24 LTS ↗，再安装 CLI。

在 Windows CMD 或 PowerShell 中运行

npm.cmd install --global --ignore-scripts https://lolicode.com/cli/downloads/lolicode-cli-0.1.0-alpha.2.tgz
lolicode.cmd

如果终端提示找不到命令，重新打开终端后再试。

在 Bash / Zsh 中运行

npm install --global --prefix "$HOME/.local" --ignore-scripts https://lolicode.com/cli/downloads/lolicode-cli-0.1.0-alpha.2.tgz
export PATH="$HOME/.local/bin:$PATH"
lolicode --version

把 PATH 设置加入 shell 配置文件后，新终端也可以直接使用。

第一次见面

安装后，进入项目目录，启动持续对话界面。

cd your-project
lolicode
/connect

在 LoliCode 提示符中输入 /connect，连接模型后就可以直接聊任务。缺配置时也会留在界面里。

密钥可从环境变量读取，也可隐藏输入供本次会话使用，不写入配置。模型调用费用由你使用的服务商计费。

按你的习惯来

聊一会儿，或交给脚本。

带着任务启动

在项目里提需求，查看工具执行过程。默认在修改和运行命令前询问你。 

lolicode "解释这个项目的结构"
lolicode run "修复测试" --approval workspace

回来接着做

对话和工具记录保存在本机，离开终端后可以恢复。

lolicode sessions
lolicode resume

给自动化一个入口

一次输出 JSON，或逐行接收事件。超时、权限和输入状态都有对应退出码。 

lolicode run "检查项目" --json
git diff | lolicode run "审阅改动" --stdin --json

选择熟悉的模型

连接兼容 API 或 LoliCode 渠道网关，保存多个渠道，按任务切换。

lolicode models
lolicode models use my-model
lolicode doctor

模型配置

你的模型，
也可以跟过来。

支持 OpenAI Completions、OpenAI Responses 和 Anthropic Messages 协议。使用服务商提供的实际地址与模型名。

下面展示 Linux 环境变量配置。Windows PowerShell 使用 $env:变量名 = '值'。 

export LOLICODE_BASE_URL='https://api.deepseek.com/v1'
export LOLICODE_MODEL='deepseek-chat'
export LOLICODE_API_KEY='你的 API Key'

cd your-project
lolicode

还有这些小事

这一版支持哪些系统？

首版已验收 Windows x64 和 Linux x64。需要 Node.js 24.9 或更新版本。其他系统和架构会继续验证。

可以关闭颜色和动画吗？

可以。使用 --plain 或设置 NO_COLOR=1 关闭颜色，使用 --no-animation 关闭等待动效。

权限如何控制？

默认 review 模式逐次确认修改和命令。workspace 允许项目操作，plan 使用只读工具，full 显式开启无限制执行。脚本模式遇到确认请求时返回相应状态，方便你接手。

会话和配置保存在哪里？

默认位于 ~/.lolicode/cli。可以通过 LOLICODE_HOME 指定目录，使用 lolicode resume 恢复该项目的最近一次 CLI 会话。
