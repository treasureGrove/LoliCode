开始使用

几行命令，见面。

先准备 Node.js 24 LTS ↗，再安装 CLI。

在 Windows CMD 或 PowerShell 中运行

npm.cmd install --global --ignore-scripts --prefer-online https://lolicode.com/cli/downloads/lolicode-cli-0.1.0-alpha.7.tgz
lolicode.cmd

如果终端提示找不到命令，重新打开终端后再试。

在 Bash / Zsh 中运行

npm install --global --prefix "$HOME/.local" --ignore-scripts --prefer-online https://lolicode.com/cli/downloads/lolicode-cli-0.1.0-alpha.7.tgz
export PATH="$HOME/.local/bin:$PATH"
lolicode

把 PATH 设置加入 shell 配置文件后，新终端也可以直接使用。

在对话里连接模型

在项目目录运行 lolicode.cmd，Linux 运行 lolicode。看到「未连接」时，在底部「消息」输入框打开服务商弹窗。

/connect

选 DeepSeek、OpenAI、Anthropic 或已保存的渠道。用方向键和回车或序号选择，按 Esc 取消。 选择预设后，选模型并在隐藏输入提示中粘贴 API Key。

连接前输入的任务会留作草稿，连好后输入 /send 发送。临时 Key 仅供本次进程使用。

常用命令

打开项目或执行任务

按 Enter 发送消息。用 PgUp、PgDn 回看，键入 / 或按 Ctrl+P 查看命令。 终端支持时，可按 Shift+Enter 或 Alt+Enter 换行。 

lolicode "./your-project"
lolicode run --dir "./your-project" "解释项目"

继续会话

对话和工具记录保存在本机，离开终端后可以恢复。

lolicode session list
lolicode -c
lolicode -s SESSION_ID

脚本输出

--format json 逐行输出 LoliCode 事件，--json 输出一个结果对象。 

lolicode run "检查项目" --format json
git diff | lolicode run "审阅改动" --stdin --json

配置与选择模型

用 /models 打开模型弹窗，按 Esc 返回。用 /connect NAME 可直接连接指定渠道。

/connect
/models

在系统终端运行 lolicode auth login NAME 配置指定渠道，或用 lolicode models --format json 获取列表。Windows 用 lolicode.cmd。

进阶设置

自定义模型与网关

在 /connect 中选自定义渠道，填写 API 基础地址并选择协议，再输入模型 ID。 支持 OpenAI Completions、OpenAI Responses 和 Anthropic Messages。 预设也可以手填模型 ID。

已保存渠道重开后可在 /connect 中补输密钥，也可预设环境变量。 DeepSeek、OpenAI 和 Anthropic 分别读取 DEEPSEEK_API_KEY、 OPENAI_API_KEY 和 ANTHROPIC_API_KEY。 

export LOLICODE_BASE_URL='https://api.deepseek.com'
export LOLICODE_MODEL='deepseek-flash'
export LOLICODE_API_KEY='你的 API Key'

cd your-project

还有这些小事

这一版支持哪些系统？

已验收 Windows x64 和 Linux x64。需要 Node.js 24.9 或更新版本。其他系统和架构会继续验证。

怎么使用逐行界面？

运行 lolicode mini 可切换到逐行界面。使用 --plain 可打开无颜色的逐行界面。 设置 NO_COLOR=1 可关闭颜色，逐行界面支持 --no-animation。

权限如何控制？

默认 review 模式逐次确认修改和命令。workspace 允许项目操作，plan 使用只读工具，full 显式开启无限制执行。脚本模式遇到确认请求时返回相应状态，方便你接手。

会话和配置保存在哪里？

默认位于 ~/.lolicode/cli。可以通过 LOLICODE_HOME 指定目录，使用 lolicode resume 恢复该项目的最近一次 CLI 会话。
