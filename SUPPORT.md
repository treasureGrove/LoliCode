# LoliCode Support / 获取帮助

## English

You can [open an issue](https://github.com/treasureGrove/LoliCode/issues/new/choose) with just a title and a description of what happened, your question, or your suggestion. The [README](README.md), [documentation index](docs/README.md), and [existing issues](https://github.com/treasureGrove/LoliCode/issues) may also help.

- Downloads and published packages: [LoliCode download page](https://lolicode.com/).
- Community and website account: [lolicode.com](https://lolicode.com/all).
- Bugs, questions, feature requests, and documentation corrections: [open an issue](https://github.com/treasureGrove/LoliCode/issues/new/choose).
- Release changes: [CHANGELOG.md](CHANGELOG.md) and [LoliCode Releases](https://github.com/treasureGrove/LoliCode-Releases/releases).
- Sensitive vulnerability reports: follow [SECURITY.md](SECURITY.md).

Version, operating system, installer or portable edition, steps, screenshots, and redacted logs are optional. For model problems, you can also add the API protocol and model name if available. Do not include API keys, passwords, tokens, private conversation content, or private endpoints.

If known, you can mention whether you were using the built-in Agent or an external AI tool. References to CC Switch in archived documentation identify the configuration foundation; LoliCode support and downloads use the addresses above.

## 中文

填写标题和具体现象、问题或建议即可[提交 Issue](https://github.com/treasureGrove/LoliCode/issues/new/choose)。也可以参考[项目介绍](README_ZH.md)、[文档导航](docs/README.md)或 [LoliCode 已有 Issue](https://github.com/treasureGrove/LoliCode/issues)。

- 下载与安装包：[LoliCode 下载官网](https://lolicode.com/)。
- 社区与网站账户：[lolicode.com](https://lolicode.com/all)。
- Bug、使用问题、功能建议和文档纠错：[提交 Issue](https://github.com/treasureGrove/LoliCode/issues/new/choose)。
- 版本变化：[更新记录](CHANGELOG.md)和 [LoliCode Releases](https://github.com/treasureGrove/LoliCode-Releases/releases)。
- 安全漏洞：按[安全策略](SECURITY.md)私下报告。

版本、系统、安装版或便携版、操作步骤、截图和脱敏日志都可选，有的话可以补充。模型相关问题也可补充协议和模型名称。不要上传 API Key、密码、令牌、私聊内容或私有接口地址。

如果清楚，也可以注明使用的是内置 Agent，还是通过 LoliCode 配置的外部工具。旧文档中的 CC Switch 属于配置基础来源；LoliCode 的下载与反馈入口以上述地址为准。
